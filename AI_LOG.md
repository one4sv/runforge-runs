# Отчёт об использовании ИИ (AI_LOG)

## Использованный инструмент

- OpenAI ChatGPT (GPT-6) — помощь в подготовке реализации интерфейса, тестовых данных, компонентов React, CSS, тестов и документации.

## Какие задачи были делегированы ИИ

- Анализ требований тестового задания и подготовка структуры React + TypeScript.
- Первичная реализация поиска, фильтрации по статусу, сортировки, сохранения фильтров в URL и панели подробностей.
- Создание оформления в молочно-тёмно-синей палитре и адаптивной вёрстки.
- Подготовка десяти тестовых запусков с логами и четырьмя статусами.
- Подготовка автоматических тестов, README.md и этого отчёта.

## Ограничения

Используется только локальный mock-сервис. Реального backend, интеграции с GitHub и запуска AI-агентов нет.
